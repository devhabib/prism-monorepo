# Security Policy

## Supported Versions

The following table shows which versions of Prism packages are currently supported with security updates.

| Version | Supported |
| :------ | :-------- |
| < 0.x   | ✅ Yes (Latest releases only) |

Since the project is in early development (0.x), only the latest published version of each package is supported. Please ensure you are running the latest version before reporting security issues.

## Reporting a Vulnerability

**DO NOT open a public GitHub issue for security vulnerabilities.**

To report a security vulnerability, please email the maintainer directly at **devhabib@outlook.com** <!-- MAINTAINER: replace with your email -->.

### What to expect:
- **Acknowledgement:** Within 48 hours of your report.
- **Investigation:** We will investigate and confirm the vulnerability.
- **Resolution:** For verified critical issues, we aim to release a patch or workaround within 14 days.

## Scope

This policy applies to vulnerabilities in the Prism library code itself (e.g., component logic, styles).

**Out of scope:**
- Issues in `devDependencies` used strictly for building or testing.
- Theoretical issues without a working Proof of Concept (PoC).
- Automated scanner reports without evidence of explotability.
