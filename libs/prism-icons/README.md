# Prism Design System (Icons)

The icon foundation for the **Prism Design System**. Contains high-quality SVG icon definitions used by `@devynelogic/prism-core`.

🔗 **[Documentation & Showcase](https://prism-ds.netlify.app/components/icons)**

## Installation

```bash
npm install @devynelogic/prism-icons
```

## Usage

Icons are exported as `PrismIconDef` objects.

```typescript
import { piUser } from '@devynelogic/prism-icons';

console.log(piUser.name); // 'user'
console.log(piUser.data); // '<path ... />'
```
