PrismDialogComponent API

Inputs and outputs for the template-based dialog component.

PrismDialogService API

Programmatic dialog service for dynamic component injection.

Usage Example:

const ref = this.dialog.open(MyComponent, {
  header: 'Title',
  data: { userId: 123 },
  width: '600px'
});

ref.afterClosed$.subscribe(result => {
  // Handle result
});

PrismDialogRef API

Methods and observables available on the dialog reference returned by the service.

Injection Tokens

Tokens for injecting data and dialog control into dynamically created components.

Component Usage:

export class MyDialogComponent {
  ref = inject(PrismDialogRef);
  data = inject(DIALOG_DATA);

  save() {
    this.ref.close({ saved: true });
  }
}

This is a signal-driven dialog with two-way binding!
