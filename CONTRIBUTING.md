# Contributing to Prism Design System

We welcome contributions!

## Setup

1. Fork and clone the repository.
2. Run `npm install`.
3. Run `npx nx serve prism-docs` to start the demo app.

## Structure

- **Core:** `libs/prism-core` (Components)
- **Theme:** `libs/prism-theme` (Styles)
- **Docs:** `apps/prism-docs` (Documentation)

## Pull Requests

Please ensure your code passes linting and tests before submitting.
